Monitoring Digital Air & Curah Hujan

Aplikasi rekap data lapangan yang berjalan langsung di browser HP atau laptop — tanpa instalasi, tanpa koneksi internet wajib.

Buka Langsung di Browser

Ukuran file kecil (± 50 KB) — aman dikirim lewat WhatsApp/email bila perlu.

Download otomatis gagal. Ketuk tombol "Buka Langsung di Browser", lalu di halaman yang terbuka gunakan menu browser ⋮ / Bagikan → Simpan Halaman / Save Page As... untuk menyimpannya secara manual.

Offline-First

Data tersimpan langsung di perangkat. Input data tetap bisa dilakukan meski sinyal hilang di lapangan.

Sinkron ke Google Sheets

Begitu tersambung internet, data terkirim ke cloud secara manual atau otomatis.

3 Jenis Data Lapangan

Curah Hujan, Water Level (Peilschaal), dan Water Depth/Water Table dalam satu aplikasi.

Ekspor ke Excel

Rekap semua data kapan saja menjadi file .xlsx multi-sheet, siap dilaporkan.

Cara Menggunakan

  1. 1

    Ketuk tombol Download Aplikasi (.html) di atas, file akan tersimpan ke folder Download di HP/laptop Anda.

  2. 2

    Buka file tersebut dari File Manager/Downloads dengan mengetuknya — file akan terbuka otomatis di browser (Chrome/Safari).

  3. 3

    Masukkan password akses aplikasi saat diminta. Belum punya password? Hubungi admin/koordinator lapangan Anda.

  4. 4

    Mulai input data survei. Aplikasi bisa dipakai berulang kali secara offline langsung dari file yang sudah diunduh.

Simpan file hasil unduhan di tempat yang mudah diakses (mis. beri pintasan di layar utama HP) agar tidak perlu memindai ulang setiap kali survei.
